# ⭐ Google Review Feedback System

![Made with PHP](https://img.shields.io/badge/Made%20with-PHP-777BB4?logo=php&logoColor=white)
![Database MySQL](https://img.shields.io/badge/Database-MySQL-4479A1?logo=mysql&logoColor=white)
![License MIT](https://img.shields.io/badge/License-MIT-green.svg)

A lightweight, self-hosted web project that allows users to submit a **star rating** via a popup interface.  
Depending on the rating, users are either redirected to your **Google Review page** or asked to provide **private feedback** stored in your local MySQL database.

---

## 🚀 How It Works

| ⭐ Rating | Action |
|-----------|---------|
| **3 stars or more** | Redirects to your business’s Google Review page |
| **Less than 3 stars** | Prompts user to submit feedback stored locally |

---

## ✨ Features

- 💫 **Responsive Popup Design** – Beautiful centered modal with smooth animations  
- ⭐ **Interactive Star Rating** – Stars illuminate dynamically on hover and click  
- 🔗 **Smart Redirection** – Sends happy users straight to your Google Reviews page  
- 📝 **Feedback Collection** – Stores feedback for low ratings in a local MySQL database  
- 🧩 **Lightweight Stack** – Uses only standard web technologies: HTML, CSS, JS, PHP, and MySQL  

---

## 🧰 Tech Stack

| Technology | Description |
|-------------|-------------|
| **HTML** | Structures the webpage |
| **CSS** | Styles and animations for popup and stars |
| **JavaScript** | Handles user interactions and redirects |
| **PHP** | Backend logic for processing and saving feedback |
| **MySQL** | Stores user feedback for internal review |
